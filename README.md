# CalorieCounter

Android-приложение для контроля питания и калорий.

Назначение

Контроль калорийности, отслеживание БЖУ, дневник питания, трекер веса и воды.

Установка

1. Клонируйте репозиторий
2. Откройте в Android Studio  
3. Настройте Supabase (скрипты в файле новаябд.txt)
4. Запустите на Android 8.0+

Использование

- Регистрация / вход
- Добавление еды (поиск, штрихкод, избранное)
- Рецепты (готовые и свои)
- Трекер веса с графиком
- Трекер воды с напоминаниями
- Календарь питания
- Настройка темы и цветов

Стек технологий

- Java
- Android API 26+
- Retrofit, OkHttp, Gson
- Supabase
- MVVM, LiveData
